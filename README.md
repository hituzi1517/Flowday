# Flowday — 動かせる勉強計画

学校・睡眠などの「固定予定」は動かさず、数学・英語などの「可動予定」を空いている時間へ並べ直す、日本語の学習スケジューラーです。外部ライブラリ、APIキー、サーバーは不要です。無料のGitHub Pagesへそのまま置けるPWA形式です。

## はじめ方

1. `flowday-pwa` フォルダ内の **全ファイルと `icons` フォルダ**を、GitHubのリポジトリ直下にアップロードします。`.nojekyll` も含めます（なくても基本動作します）。
2. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch**、ブランチを **main / (root)** にして保存します。表示されたPages URLを開きます。
3. iPhone/iPadのSafariでページを開き、共有メニューから **ホーム画面に追加** を選び、アプリとして利用します。初回アクセス後はオフラインでも起動できます。
4. `index.html` をPCで直接開くと、スケジューラー本体は動きますが、PWA登録とオフラインキャッシュにはHTTPSまたはlocalhostが必要です。

## 毎晩の予定入力

日付を「明日」にし、テンプレートを修正して「時間割を作成・更新する」を押します。曜日ごとの基本形と毎日の基本形を保存できます。新しい日を初めて表示すると、その曜日のテンプレート（なければ毎日の基本形）が使われます。

```
【固定】
睡眠 23:30-07:00
学校 09:00-16:00
服薬 21:00-21:05

【可動】
数学 120 @17:00
英語 60
物理 90
風呂 30 @20:00
歯磨き 10
```

固定予定のうち終了時刻が開始時刻より前なら、翌日の終了時刻として扱います。前日に作成した睡眠予定は、次の日の0時〜起床時刻にも反映されます。可動予定の `@17:00` は **17時以降の開始** の指定です。時間を省略すると上から順に空き時間へ配置します。「起床など」の欄より前には可動予定を配置しません。

## ずれたとき

- 「+5分遅らせる」：選択した可動予定の開始を5分後ろにずらし、それ以降を再配置します。
- 「+5分延長」：選択した可動予定の作業時間を5分増やし、後続を再配置します。
- 「完了」：当日なら実際の終了時刻を任意で記録し、**予定より遅く終わった場合**の遅れを後続へ反映します。早く終わっても自動で前倒しにはしません。
- 固定予定をまたぐと、可動予定を分割して固定予定の後に再開します。当日に収まらなかった部分は「翌日に繰り越す」で翌日の可動予定の先頭へ追加できます。実行済みの繰り越しは再実行しません。

**仕様上の注意：** 可動予定は入力順を守ります。`@HH:MM` は最早開始時刻であり、固定の予約時刻ではありません。就寝予定と他の固定予定が重なるなど固定予定同士の重複は自動修正せず警告します。「完了」の実際の終了は、遅れだけに反映します。翌日への繰り越しはボタンを押した時点の残り時間のスナップショットであり、元の日で予定をあとから変えても自動同期されません。日をまたぐ可動予定の自動実行・通知はありません。

## 保存と安全性

予定は、このPWAを開いた端末の `localStorage` に保存されます。クラウド同期・ログイン・外部送信はありません。iPhoneとiPadは自動同期しません。「JSONで保存」と「JSONを読み込む」で手動移動できます。読み込みは**既存データを全部置き換える**ため、先にバックアップしてください。ブラウザデータ削除時に消える可能性があります。

**指定時刻のプッシュ通知は未搭載です。** iPhoneでアプリを閉じていても通知を届けるには、ホーム画面への追加に加え、購読情報を保持・送信するプッシュサーバー等が必要です。GitHub Pagesの静的ファイルだけでは決まった時間のバックグラウンド通知は保証できません。

## 構成

`index.html`, `style.css`, `app.js`, `planner.js`, `sw.js`, `manifest.webmanifest`, `icons/`, `.nojekyll` が公開に必要です。`tests/` は日割り計算の動作確認に使った開発用テストで、公開時には省略しても構いません。

ローカルテスト：`node tests/planner.test.js`。また、フォルダ内で `python -m http.server 8000` を実行し、`http://localhost:8000/` でブラウザ表示を確認できます。
